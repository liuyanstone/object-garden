# Object Garden / 寻物小花园

Each **90-second** round chooses **150 different objects** from a catalog of **1,000 distinct illustrations**. Every displayed object appears exactly once. The field has irregular positions, sizes and rotations, with no grid or cards. Circular art/hit bounds are checked for spacing. Positions stay fixed during the round and are reproducible on reload at the same width. Objects have a minimum 46 CSS pixel tap diameter; scroll vertically to explore the field on smaller screens.

Targets are **text only**. A shuffled target order contains each displayed object once, with no repeats throughout the round. Correct taps earn 100 points; wrong taps keep the current target and do not advance the order or subtract points. Finding all 150 objects ends the round immediately with 15,000 points. Otherwise the round ends after 90 seconds of active play. The saved order and progress survive pause/resume and reload without resetting to previously requested objects. At the end, a review card shows the name and illustration of the target that was active when time ran out. A perfect round shows the last found object instead. No picture hints are shown during active play. Local images are prepared before the active timer starts; failed downloads leave the timer stopped and can be retried.

English/Chinese, large text, touch/keyboard-accessible buttons, gentle synthesized sounds, mute control, pause/resume, automatic pause on tab switch/window blur, saved unfinished rounds, replay, and highest completed score per local day. Progress is local to the same browser and device; no login or backend. Earlier completed daily bests are retained. Older active rounds restart under the new no-duplicate rules.

The catalog contains 30 original SVGs, 139 adapted Lucide illustrations, 668 OpenMoji illustrations and 163 Game-icons.net illustrations. All 1,000 IDs, English names and Chinese names are distinct. Core Unicode entries were curated to exclude skin tones, gender variants, color-only copies, clock-time variants and repeated views/states of the same object. Source artwork and names include some specialist objects as well as everyday objects, animals, foods and natural features.
